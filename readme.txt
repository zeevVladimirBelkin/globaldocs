The application requires J2SE 1.5+ to run (or to build).

To build the Globaldocs you may use
Netbeans 5+ IDE or a standalone ant.

To build the windows louncher use
  Bloodshed C++ IDE (http://www.bloodshed.net/devcpp.html)
or a standaline MINGW
  (http://www.mingw.org/)

To run the application use the:
  java -Xmx100M -jar globaldocs.jar
command.

Using of the webstart: 
   htpp://globaldocs.zevbelkin.com/globaldocs.jnlp
is the preferred way to install the application.


The project home is: http://globaldocs.zeevbelkin.com
